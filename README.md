## 一句话概括最终框架

> 鱼种 = 基础属性 + 习性模式集合（主/副/生命周期/避险）；每个模式 = 空间模板 × 摄食模板 × 条件模板；条件模板输出四个通道：**Supply**（今天这种鱼总量多少）、**Scope**（模式今天成不成立，决定模式份额）、**P**（空间适宜度，决定鱼在哪）、**A**（摄食激活度，决定鱼想不想吃）；模式份额混合（非胜者独占）；场景内做容量加权归一化守恒鱼量；实时中鱼 = 烘焙权重 × A 响应 × 饵/手法/距离匹配。

## 本次生产级下钻对原框架的主要修正（详见 02 文档 D1–D12）

1. **胜者独占模式选择 → 模式份额混合**（消除阈值抖动，恢复多群体并存，吸收原 FishGroup 轴）
2. **模式价值公式中 P 的双重角色 → Scope/P 拆分**（消除循环依赖）
3. **P 加权算术平均 → 硬Gate × 几何核心 × 限幅修正 三层聚合**（恢复 AND 语义）
4. **运行时模板继承 → 模板即宏（复制+溯源）**（消除菱形继承与合并顺序歧义）
5. **四档状态从计算量降级为展示投影**（计算全程使用连续值 A）

## R1.1 修订（2026-09-10，06 独立复核并入）

- **F1**：份额归一 softmax → **幂归一**（零保持零；无压力时避险份额恰为 0；SCOPE 全零兜底）
- **F2**：A 增加 **veto 乘性上限包络**（`A = min(加性和, Π cap)`；标准 veto 包随宏默认带入，编译期强制）
- **F3**：运行时三 Match → **AnglerMatch 几何合成**（λ 指数显式控制压缩度，解耦 NONE 标定）
- **F4（已决策）**：平滑移至**环境事实侧，内核无状态**（可并行/局部重烘/单切片回放；份额侧 EMA 存档否决）
6. **删除 StatePositionModifier**（避免 A 双重生效）
7. **恢复 QualityShare（体型轴）与 Supply（总量）通道**（补回压缩时丢失的两个必要轴）
